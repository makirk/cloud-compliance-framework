# EntraID.OPS.2.Access-Reviews: Periodic access reviews must be conducted for all privileged roles and group memberships

**Severity:** High
**Service:** Azure Entra ID
**Applicable Standards:** Microsoft Cloud Security Benchmark PA-4, FedRAMP AC-2, SOC 2 CC6.2

## Description
Entra ID Access Reviews must be configured and conducted on a regular schedule for all privileged directory roles, Azure resource roles, security group memberships, and access to enterprise applications. Access reviews for privileged roles should be conducted at least quarterly, and reviews for general group memberships and application access should be conducted at least semi-annually. Reviewers must validate that access is still required and appropriate for each user. Stale accounts that have not been used within a defined period must be identified and disabled or removed. Access review results must be documented and remediation actions must be tracked to completion.
