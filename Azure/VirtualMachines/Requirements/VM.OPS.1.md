# VM.OPS.1.Automatic-Guest-Patching: Enable Azure Update Manager or Auto Guest Patching for automated security updates

**Severity:** High
**Service:** Azure Virtual Machines
**Applicable Standards:** Microsoft Cloud Security Benchmark PV-6, FedRAMP SI-2, SOC 2 CC7.1

## Description
Use Azure Update Manager or enable Automatic VM Guest Patching to ensure the most recent security updates are installed. Auto Guest Patching automatically assesses and updates Azure virtual machines with Critical and Security updates released each month during off-peak hours. System updates should be installed on machines to prevent missing security system updates.

Source: https://learn.microsoft.com/en-us/security/benchmark/azure/baselines/virtual-machines-linux-security-baseline#pv-6-rapidly-and-automatically-remediate-vulnerabilities
