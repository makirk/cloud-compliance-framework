# VM.SEC.7.Defender-For-Servers-EDR: Enable Microsoft Defender for Servers for endpoint detection and response

**Severity:** High
**Service:** Azure Virtual Machines
**Applicable Standards:** Microsoft Cloud Security Benchmark LT-1, ES-1, FedRAMP SI-4, SOC 2 CC7.2

## Description
Enable Microsoft Defender for Servers which integrates with Microsoft Defender for Endpoint to provide endpoint detection and response (EDR). Defender for Servers provides security baselines, OS level assessments, vulnerability assessment scanning, adaptive application controls (AAC), file integrity monitoring (FIM), and advanced threat protection for Windows and Linux machines.

Source: https://learn.microsoft.com/en-us/security/benchmark/azure/baselines/virtual-machines-linux-security-baseline#lt-1-enable-threat-detection-capabilities
