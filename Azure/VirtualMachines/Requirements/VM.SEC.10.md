# VM.SEC.10.Anti-Malware-Solution: Deploy anti-malware solution on virtual machines

**Severity:** Medium
**Service:** Azure Virtual Machines
**Applicable Standards:** Microsoft Cloud Security Benchmark ES-2, ES-3, FedRAMP SI-3, SOC 2 CC6.8

## Description
Virtual machines must have an anti-malware solution deployed with health status monitoring for platform, engine, and automatic signature updates. For Linux VMs, Microsoft Defender for Endpoint for Linux or a third-party anti-malware product should be installed. Endpoint protection health issues must be resolved to protect against the latest threats and vulnerabilities.

Source: https://learn.microsoft.com/en-us/security/benchmark/azure/baselines/virtual-machines-linux-security-baseline#es-2-use-modern-anti-malware-software
