# VM.SEC.8.Vulnerability-Assessment-Enabled: Enable vulnerability assessment scanning via Microsoft Defender

**Severity:** High
**Service:** Azure Virtual Machines
**Applicable Standards:** Microsoft Cloud Security Benchmark PV-5, FedRAMP RA-5, SOC 2 CC7.1

## Description
A vulnerability assessment solution should be enabled on virtual machines. Virtual machines must be audited to detect whether they are running a supported vulnerability assessment solution. Identification and analysis of vulnerabilities is a core component of every cyber risk and security program.

Source: https://learn.microsoft.com/en-us/security/benchmark/azure/baselines/virtual-machines-linux-security-baseline#pv-5-perform-vulnerability-assessments
