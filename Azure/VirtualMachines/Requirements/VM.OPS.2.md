# VM.OPS.2.Azure-Backup-Enabled: Enable Azure Backup with appropriate frequency and retention periods

**Severity:** Medium
**Service:** Azure Virtual Machines
**Applicable Standards:** Microsoft Cloud Security Benchmark BR-1, FedRAMP CP-9, SOC 2 A1.2

## Description
Enable Azure Backup for virtual machines with desired frequency and retention periods. If Azure Disk Encryption is in use, Azure VM backup automatically handles the backup of customer-managed keys. Use Azure Policy to enable automatic backups and ensure protection of Azure Virtual Machines.

Source: https://learn.microsoft.com/en-us/security/benchmark/azure/baselines/virtual-machines-linux-security-baseline#br-1-ensure-regular-automated-backups
