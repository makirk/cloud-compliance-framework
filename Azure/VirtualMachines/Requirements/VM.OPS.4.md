# VM.OPS.4.Adaptive-Application-Controls: Use Defender adaptive application controls to restrict allowed applications

**Severity:** Medium
**Service:** Azure Virtual Machines
**Applicable Standards:** Microsoft Cloud Security Benchmark AM-5, FedRAMP CM-7, SOC 2 CC6.8

## Description
Use Microsoft Defender for Cloud adaptive application controls to discover applications running on virtual machines and generate an application allow list. This mandates which approved applications can run in the VM environment, helping harden machines against malware by using machine learning to analyze running applications and suggest known-safe applications.

Source: https://learn.microsoft.com/en-us/security/benchmark/azure/baselines/virtual-machines-linux-security-baseline#am-5-use-only-approved-applications-in-virtual-machine
