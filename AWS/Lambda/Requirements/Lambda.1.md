# Lambda.1: Lambda function policies should prohibit public access

**Severity:** Critical
**Service:** AWS Lambda
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether the Lambda function resource-based policy prohibits public access outside of your account. The control fails if public access is allowed.

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/lambda-controls.html#lambda-1
