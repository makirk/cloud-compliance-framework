# EC2.SEC.6.VPC-Flow-Logging: VPC flow logging should be enabled in all VPCs

**Severity:** Medium
**Service:** Amazon EC2
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether Amazon VPC flow logs are found and enabled for VPCs. VPC Flow Logs is a feature that enables you to capture information about the IP traffic going to and from network interfaces in your VPC.
