# S3.8: S3 general purpose buckets should block public access at the bucket level

**Severity:** High
**Service:** Amazon S3
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether an S3 general purpose bucket has bucket-level public access blocks applied. The control fails if any of the following settings are set to false: BlockPublicAcls, BlockPublicPolicy, IgnorePublicAcls, RestrictPublicBuckets.
