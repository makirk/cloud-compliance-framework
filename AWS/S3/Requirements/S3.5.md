# S3.5: S3 general purpose buckets should require requests to use SSL

**Severity:** Medium
**Service:** Amazon S3
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether S3 general purpose buckets have policies that require requests to use SSL/TLS. The control fails if the bucket policy doesn't explicitly deny access to HTTP requests.

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/s3-controls.html#s3-5
