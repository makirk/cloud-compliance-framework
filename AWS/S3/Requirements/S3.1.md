# S3.1: S3 general purpose buckets should have server-side encryption enabled

**Severity:** Medium
**Service:** Amazon S3
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether Amazon S3 general purpose buckets have server-side encryption enabled. The control fails if the S3 bucket does not have server-side encryption enabled.

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/s3-controls.html#s3-1
