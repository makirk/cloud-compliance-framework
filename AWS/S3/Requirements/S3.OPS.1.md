# S3.OPS.1.Lifecycle-Policies: S3 buckets should have lifecycle policies configured

**Severity:** Medium
**Service:** Amazon S3
**Applicable Standards:** AWS Operational Best Practices, AWS Well-Architected Framework

## Description
This operational control checks whether S3 buckets have lifecycle policies configured to manage object storage classes and expiration. Lifecycle policies help optimize storage costs by automatically transitioning objects to more cost-effective storage classes (such as S3 Glacier) or deleting objects that are no longer needed. This is especially important for buckets containing logs, backups, or temporary data that can be archived or deleted after a certain period.

Source: https://docs.aws.amazon.com/AmazonS3/latest/userguide/object-lifecycle-mgmt.html
