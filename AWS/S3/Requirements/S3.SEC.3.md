# S3.SEC.3.No-Public-Write: S3 general purpose buckets should prohibit public write access

**Severity:** Critical
**Service:** Amazon S3
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether your S3 general purpose buckets allow public write access. It evaluates the Block Public Access settings, the bucket policy, and the bucket access control list (ACL).

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/s3-controls.html#s3-3
