# IAM.7: Password policies for IAM users should have strong configurations

**Severity:** Medium
**Service:** AWS IAM

## Description
This control checks whether the account password policy for IAM users uses strong configurations. The control fails if the password policy does not use strong configurations including minimum length, complexity requirements, and expiration settings.
