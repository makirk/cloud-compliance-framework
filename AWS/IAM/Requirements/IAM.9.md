# IAM.9: MFA should be enabled for the root user

**Severity:** Critical
**Service:** AWS IAM
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether MFA is enabled for the root user. The root user has complete access to all AWS services and resources in the account. MFA adds an extra layer of protection on top of a username and password.
