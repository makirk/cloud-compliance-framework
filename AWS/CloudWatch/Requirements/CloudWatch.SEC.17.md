# CloudWatch.SEC.17.Alarm-Actions-Enabled: CloudWatch alarm actions should be enabled

**Severity:** High
**Service:** Amazon CloudWatch
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether CloudWatch alarm actions are in enabled state. The control fails if the alarm action for an alarm is in disabled state.

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/cloudwatch-controls.html#cloudwatch-17
