# RDS.SEC.6.Enhanced-Monitoring: Enhanced monitoring should be configured for RDS DB instances

**Severity:** Low
**Service:** Amazon RDS
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether enhanced monitoring is enabled for your RDS DB instances. Enhanced monitoring provides real-time metrics for the operating system that your DB instance runs on.

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/rds-controls.html#rds-6
