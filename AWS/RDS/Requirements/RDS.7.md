# RDS.7: RDS clusters should have deletion protection enabled

**Severity:** Low
**Service:** Amazon RDS

## Description
This control checks whether RDS clusters have deletion protection enabled. The control fails if deletion protection is not enabled. Enabling deletion protection is an additional layer of protection against accidental database deletion.
