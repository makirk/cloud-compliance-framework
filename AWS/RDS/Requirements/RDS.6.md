# RDS.6: Enhanced monitoring should be configured for RDS DB instances

**Severity:** Low
**Service:** Amazon RDS

## Description
This control checks whether enhanced monitoring is enabled for your RDS DB instances. Enhanced monitoring provides real-time metrics for the operating system that your DB instance runs on.
