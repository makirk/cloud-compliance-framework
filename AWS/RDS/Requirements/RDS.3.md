# RDS.3: RDS DB instances should have encryption at-rest enabled

**Severity:** Medium
**Service:** Amazon RDS
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether storage encryption is enabled for your Amazon RDS DB instances. The control fails if storage encryption is not enabled. Data at rest refers to any data that is stored in persistent, non-volatile storage.

Source: https://docs.aws.amazon.com/securityhub/latest/userguide/rds-controls.html#rds-3
