# RDS.10: IAM authentication should be configured for RDS instances

**Severity:** Medium
**Service:** Amazon RDS
**Applicable Standards:** AWS Foundational Security Best Practices v1.0.0, CIS AWS Foundations Benchmark v1.2.0

## Description
This control checks whether an RDS DB instance has IAM database authentication enabled. IAM database authentication allows authentication to database instances with an authentication token instead of a password.
